## Rejected (checked against the code)

- "fetch rejection is not retried": a rejected fetch (network, timeout) throws into `embedBatchWithStallRetry`, whose transient pattern covers `fetch failed`/`ECONNRESET`/timeouts — the provider retry is only for the 400 that path treats as final.
- "`updated_at` is not a field of the registry record": `RepoMeta` entries carry it (live entry for tsp-wt-import-jev: `updated_at: 1791815450156`).
- "tsp-wt-import-* names carry no `@`": registry names are `local/rdesigner@tsp-wt-import-jev`.
- "family by `@` prefix is not proof of the same repository": a wrong family member costs only re-embedding — reuse needs the symbol id (which carries file and line) AND the text hash to match.
- "the history search does not check repository identity": a commit sha in this tree's history is this repository by construction.
- "mutable retry delays can leak between concurrent embeddings": only the test-only setter writes them.
- "headHistory/listRepos failures are swallowed": deliberate — the clone is best effort; every caller embeds from scratch when it finds no donor.
