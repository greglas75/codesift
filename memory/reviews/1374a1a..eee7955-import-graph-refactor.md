# Import graph refactor review

## Scope and verdict

Tier 3 self-review of the import-graph refactor and its review-driven bug fixes. The public
`src/utils/import-graph.ts` facade is preserved while collection, resolution, language parsing,
edge accumulation, metrics, and workspace handling move into focused modules. Verdict: APPROVE;
no open ship-blocking findings.

## Review evidence

- CodeSift `review_diff` on the final `origin/main...HEAD` range: secrets, breaking changes,
  coupling, complexity, dead code, and bug patterns passed. Blast-radius and hotspot warnings are
  expected for this central utility. Its filename-based test-gap warnings are false positives: the
  extracted modules are imported by the dedicated import-graph suites.
- Cross-provider review used Cursor and Claude across the complete production diff, followed by
  fresh appended passes for the final workspace-entry commits. Findings about null parser trees,
  root escapes, Kotlin ambiguity, edge metadata, workspace boundaries, and authoritative exports
  were fixed in-run. Findings describing removed monolithic code, unrelated repositories, or
  deliberately fail-closed behavior were dispositioned as non-regressions.
- GitHub CodeQL identified a first-match-only replacement in tsconfig alias targets. Commit
  `0756427` changes it to global replacement and adds a repeated-wildcard regression test; all
  underlying CodeQL language analyses otherwise passed.
- GitHub's Node 20/22 matrix exposed failures already present on `main`: Node 20 executed direct
  `node:sqlite` contracts, one test used the Node 22-only `globSync`, and a cache test inherited the
  host's memory budget. The repair excludes only SQLite-specific contracts on unsupported runtimes,
  uses portable recursive traversal, and fixes the test cache budget explicitly.
- CQ1-CQ40 and the behavior/structure roles found no critical gate failure. Module dependencies are
  one-way toward sibling helpers; no extracted module imports the facade, so the split introduces
  no barrel cycle. Public exports remain stable.
- Q1-Q25 review found causal assertions for parser fallback, path ambiguity, Kotlin package
  matching, duplicate-edge metadata, PageRank resilience, workspace boundaries, package export
  precedence, and repeated wildcard expansion. No test uses implementation-only source inspection
  as its oracle.
