# changed_symbols(include_diff): a diff over 50 KB came back as null

git ran with a 50 KB maxBuffer while only 500 characters are kept, so a larger diff threw and the catch
returned `diff: null`. The regression test (real repo, ~400 KB diff) failed on the old code.

Two review rounds (zuvo/proofs/1e5d044-changed-symbols-buffer.txt, then aa3d345-git-prefix.txt):
- round 1: raising the buffer to 64 MB still buffered the whole diff to keep 500 chars and still failed
  past it → replaced by `runGitPrefix`, which streams stdout and stops git after `maxChars` (never mid
  surrogate pair); the test no longer depends on diff-prefix config and restores CODESIFT_DATA_DIR;
- round 2: stdout is destroyed after the kill (SIGPIPE even if SIGTERM is ignored), and a signal kill is
  reported as such instead of "exited with null".

Rejected: chunk-size memory (a pipe chunk is at most 64 KB); ref injection (since/until are validated by
`runGitDiff` before this read); the "50 KB" comment (it describes the original code); the bare catch
returning null (the field's documented contract, unchanged).
