# Chunk publication and cache-coherence review

The ship review found failure and concurrency risks in the chunk persistence path. The final
implementation publishes complete generation-specific chunk and embedding files through one
atomically replaced manifest. Semantic queries resolve that manifest once, pin both inputs to the
same immutable generation, and bind cache/in-flight state to the resolved source and invalidation
epoch. Writable errors are observed from the first write and resident embedding loads are bounded.

All critical findings from the iterative adversarial passes were fixed. The final multi-provider
production review reported no critical blockers. Remaining warnings cover explicit degradation
when the configured memory budget is exceeded, diagnostics for damaged files, and future garbage
collection of retained generations; none permits mixed-generation publication or stale cache reuse.
