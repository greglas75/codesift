## Rejected

- "files delete leaves base symbols visible" (kimi, qwen, codex-5.3): a plain table keeps a file's
  symbols when only its file row is deleted too; the overlay must match plain, and the differential
  test enforces it. Every writer deletes symbols first.
- "UNION ALL not rowid-ordered, keyset paging drops rows" (qwen): every paged query is
  `WHERE rowid > ? ORDER BY rowid` on the view (queries.ts, index-io.ts, store.rs); AP1 streams
  547,025 rows with 300 copy-on-touch files interleaved, 0 diffs.
- "no INSTEAD OF UPDATE / INSERT OR IGNORE reinterpretation" (claude, qwen): no writer in src/ or the
  crate issues UPDATE or OR IGNORE on symbols/files (git grep); all writers are in the differential test.
- "ATTACH does not accept a bound parameter" (openrouter-4): it does; tested in both SQLite copies.
- "repo used before declaration in findSymbolsByRequestedIdsSqlite" (byteplus-3): declared above.
- "NATIVE_ABI bumped without the crate" (openrouter-4): lib.rs ABI_VERSION = 27 in the same commit.
- "applyIndexDelta INSERT conflicts on an existing path" (openrouter-4): plain connections use the
  UPSERT statement, overlays the trigger's upsert (insertFileSqlFor).
- "applyIndexDelta / setFileMtimes skip the write lock" (claude): synchronous transactions with no
  yield, the same contract as saveIncrementalSqlite, which also has none; pre-existing exposure.
- "sameSymbols order-sensitive", "symbolKey prefix overlap" (openrouter-4): a false "changed" only
  copies that file (the plain path rewrites everything); the two prefixes cannot overlap.
- "lossy marker not cleared on a delta" (claude): correct — a partial re-parse must not clear it.
- "seed deletes the target before rename" (codex-5.3): stale -wal/-shm must not be replayed onto the
  new database; the seed only runs when there is no usable index.
- "VACUUM INTO copy then SCHEMA_SQL fails", "-wal/-shm of bases" (openrouter-4, kimi): IF NOT EXISTS
  DDL; bases are journal_mode=DELETE.
- "overlay vectors under two prefixes" (claude): documented — vectors rebase to the base prefix, the
  few delta rows re-embed.
- "absolute base path in meta", "process.pid temp dirs in tests", "magic size bound in a test"
